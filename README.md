# 오류고등학교 VR 학교 안내 웹 브로셔 + VR탐방 게임

360도 사진으로 교정을 둘러보는 오류고등학교 웹 브로셔와, 같은 사진으로 만든 게임 두 가지(VR 보물찾기, 틀린 그림 찾기)를 한 저장소에서 GitHub Pages로 호스팅합니다.

- 브로셔: https://oryu2027.github.io/oryu/
- VR 보물찾기: https://oryu2027.github.io/oryu/treasure-hunt.html
- 틀린 그림 찾기: https://oryu2027.github.io/oryu/spot-the-difference.html

## 파일 구성

| 파일 | 내용 | 크기 |
|---|---|---|
| `index.html` | 학교 안내 브로셔. 오픈캠퍼스 참여 신청 바로 아래 'VR탐방 게임' 영역에서 두 게임으로 이동 | 약 10MB |
| `treasure-hunt.html` | VR 보물찾기 | 약 8MB |
| `spot-the-difference.html` | 틀린 그림 찾기 | 약 5MB |
| `보물찾기_결과수집_AppsScript.gs` | 보물찾기 결과를 구글 시트에 모으는 스크립트(구글 시트에 붙여 넣어 사용) | |
| `README.md` | 이 안내문 | |

세 HTML 파일에는 사진, 배경 음악, 3D 화면 프로그램(three.js)이 모두 들어 있습니다. 별도의 폴더나 빌드 과정 없이 그대로 올리면 되고, 학교 인터넷에서 외부 사이트가 차단되어도 동작합니다.

파일끼리는 계정 주소가 아니라 **파일 이름으로** 연결되어 있습니다(GitHub Pages에서 열었을 때. 파일을 내려받아 직접 열면 '돌아가기'는 https://oryu2027.github.io/oryu/ 로 갑니다). 그래서 GitHub 계정이 바뀌어도 세 파일을 새 계정의 저장소에 함께 올리기만 하면 링크가 그대로 동작합니다. **파일 이름은 바꾸지 마세요.**

## GitHub Pages로 호스팅하기

1. 이 저장소(`oryu2027/oryu`, **Public**)에서 [Add file] → [Upload files]를 누르고, 세 HTML 파일을 한꺼번에 끌어다 놓은 뒤 [Commit changes]를 누릅니다.
2. **Settings → Pages**로 이동합니다.
3. **Build and deployment → Source**를 `Deploy from a branch`로 두고, **Branch**는 `main`, 폴더는 `/ (root)`로 선택한 뒤 저장합니다.
4. 1~2분 뒤 https://oryu2027.github.io/oryu/ 로 접속해 확인합니다.

수정본을 올릴 때도 같은 이름으로 다시 올리면 덮어쓰기되고, 1~2분 뒤 반영됩니다. 예전 화면이 보이면 `Ctrl + F5`로 새로고침하세요. 두 게임 모두 시작 화면 닉네임 칸 아래의 **버전** 표시로 최신본인지 확인할 수 있습니다.

## VR 보물찾기 (`treasure-hunt.html`)

- 닉네임을 입력하고 교정 **7곳**(오류고 전경, 작은 정원, 청운실, 체육관, 클라이밍실, 도서관, 과학실)을 360°로 둘러보며, 장소마다 깜박이는 보물 **5개씩, 모두 35개**를 찾습니다.
- 보물을 찾으면 그 자리에 대한 짧은 소개가 나옵니다(예: 체육관 '헬스장', 클라이밍실 '디지털 클라이밍', 과학실 '전자칠판').
- 한 장소에서 5개를 모두 찾으면 '다음 장소' 버튼으로 바로 이동할 수 있습니다.
- 결과 화면: 찾은 보물 수, 둘러본 장소, 걸린 시간, 장소별 기록과 칭호. 아래에 **참여자 결과판**(날짜 선택, 순위)이 나옵니다.
  - 순위: 보물을 많이 찾은 순, 같으면 빨리 끝낸 순
  - **엑셀로 내려받기**: '전체' 시트 + 날짜별 시트(그날 순위)
- 결과 화면의 **탐방 시작**은 닉네임 칸이 빈 첫 화면으로 돌아가, 다음 참여자가 새 닉네임부터 입력합니다.
- **배경 음악**: 경쾌한 마림바 곡이 시계 초침 같은 리듬과 함께 반복되고, 1분마다 조금씩 빨라집니다(10분 뒤 가장 빠른 속도). 오른쪽 위 ▶/⏸ 버튼으로 켜고 끕니다.
  - 브라우저 정책상, 화면을 한 번도 누르지 않은 상태에서는 소리가 나지 않을 수 있습니다. 이때는 닉네임 칸 등 화면을 처음 누르는 순간 음악이 시작됩니다.
  - 교실 PC에서 바로 나오게 하려면: 크롬 주소창 왼쪽 아이콘 → [사이트 설정] → [소리] → '허용'.

### 참여 결과를 날짜별로 계속 모으기 (구글 시트 연결, 두 게임 공통)

결과 저장 주소를 넣지 않으면 결과는 **그 PC의 브라우저에만** 저장됩니다. 이 경우 PC 초기화 프로그램이나 방문 기록 삭제가 돌면 결과가 사라집니다(결과판에 빨간 안내문이 표시됨). 여러 기기의 결과를 날짜별로 계속 모으려면 구글 시트를 연결하세요. 웹 앱 주소 하나를 두 게임이 함께 씁니다.

1. 구글 시트 'VR 보물찾기 결과'에서 [확장 프로그램] → [Apps Script]를 엽니다.
2. 이 저장소의 `보물찾기_결과수집_AppsScript.gs` 내용을 모두 붙여 넣고 저장합니다.
3. [배포] → [새 배포] → 유형 '웹 앱' → 실행: **나**, 액세스 권한: **모든 사용자** → [배포] 후 권한을 허용합니다.
4. 나온 **웹 앱 주소**(`https://script.google.com/macros/s/…/exec`)를 `treasure-hunt.html`과 `spot-the-difference.html` **두 파일 모두**의 아래 줄 따옴표 안에 넣고 이 저장소에 다시 올립니다.
   ```js
   var RESULT_URL = '';
   ```
   시트 편집 주소(`docs.google.com/spreadsheets/…`)가 아니라 **웹 앱 주소**여야 합니다.

연결 후에는 보물찾기 결과가 '결과' 탭에, 틀린 그림 찾기 결과가 '틀린그림 결과' 탭에 날짜와 함께 한 줄씩 쌓이고 지워지지 않습니다. 시트에서 '날짜' 칸에 필터를 걸면 날짜별로 볼 수 있습니다. 결과는 GitHub 계정과 무관하게 구글 시트에 남으므로, 게임을 다른 계정으로 옮겨도 기록이 이어집니다.

## 틀린 그림 찾기 (`spot-the-difference.html`)

- 닉네임을 입력하고 교정 **5곳**(도서관, 과학실, 급식실, 매점, 클라이밍실)의 원래 사진과 바뀐 사진을 비교해, 장소마다 다른 곳 **5개**를 찾습니다.
- 장소당 제한 시간 **90초**, 엉뚱한 곳을 누르면 **2초** 감점됩니다. 사진 위에서 마우스 포인터는 손가락 모양입니다.
- **60초 안에 5곳을 모두 찾으면** '5곳 모두 찾았어요!' 안내와 함께 3초 뒤 자동으로 다음 장소(마지막이면 최종 결과)로 넘어갑니다. 60~90초 사이에 다 찾으면 '다음 장소' 버튼을 눌러 넘어갑니다.
- 시간 안에 못 찾으면 **정답 5곳이 두 사진에 테두리로 표시**됩니다(빨간 점선 = 놓친 곳). 확인한 뒤 '다음 장소'로 넘어갑니다.
- 장소마다 **다른 배경 음악**이 흐르고, 남은 시간이 줄수록 조금씩 빨라지며 마지막 15초에는 한 번 더 빨라집니다. 오른쪽 위 ▶/⏸ 버튼으로 켜고 끕니다.
- 시간 안에 다 찾은 장소 수로 최종 레벨이 정해집니다: Lv.1 새내기 관찰자(0곳) · Lv.2 호기심 탐험가(1~2곳) · Lv.3 눈썰미 탐정(3곳) · Lv.4 매의 눈(4곳) · Lv.5 오류고 명탐정(5곳).
- 결과 화면에 **참여자 결과판**(날짜 선택, 순위)이 나오고, **엑셀로 내려받기**('전체' 시트 + 날짜별 시트)를 할 수 있습니다. 순위는 다 찾은 장소 수 → 찾은 틀린 곳 수 → 걸린 시간 순입니다. 첫 화면의 '참여 결과판' 버튼으로도 볼 수 있습니다.
- 오른쪽 위 **← 브로셔로 돌아가기** 버튼은 닉네임 화면부터 게임 중, 결과 화면까지 언제든 보입니다.
- 게임 중에는 **↺ 처음으로** 버튼으로 닉네임 화면으로 돌아가 다시 도전할 수 있습니다(닉네임은 그대로 채워짐).
- 게임 도중에 '브로셔로 돌아가기'·'처음으로'를 누르거나 창을 닫아도, 그때까지의 기록이 **'중간 종료'** 표시와 함께 결과판(구글 시트의 칭호 칸에도 '(중간 종료)')에 저장됩니다. 시작하자마자(3초 이내, 찾은 곳 없음) 나가면 저장하지 않습니다.
- 제한 시간·감점·자동 넘김 기준(60초)·레벨 이름은 파일 스크립트 맨 위 '선생님이 바꿀 수 있는 설정'에서 바꿀 수 있습니다.

## 참고

- **같은 브로셔를 두 주소에 올립니다.** 이 `index.html`을 옛 주소 저장소(`oryu2026/oryu`)에도 그대로 올리면 https://oryu2026.github.io/oryu/ 에서도 같은 브로셔(오픈캠퍼스 신청 + 게임)가 열립니다. 게임이 없는 oryu2026에서는 게임 카드가 자동으로 oryu2027의 게임 주소로 연결됩니다. 브로셔를 고칠 때는 두 저장소에 같은 파일을 함께 올려 주세요.
- 오픈캠퍼스 참여 신청 버튼은 별도의 신청 링크로 연결됩니다.

- 사진이나 문구를 바꾸려면 해당 HTML 파일을 다시 만들어 같은 이름으로 덮어써 주세요.
